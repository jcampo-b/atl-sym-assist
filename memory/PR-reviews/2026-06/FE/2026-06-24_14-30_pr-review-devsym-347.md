## Findings

### SHOULD-FIX

**`src/components/wizard/WizardStepper.tsx:54-56`**
- Severity: should-fix
- What: `sm:truncate` and `sm:text-clip` both target `text-overflow` at the sm breakpoint — one sets `text-overflow: ellipsis`, the other `text-overflow: clip`. Winner depends on Tailwind internal class-generation order (non-deterministic from source).
- Why: Conflicting Tailwind utilities on same CSS property — fragile across Tailwind versions.
- Fix: Drop `sm:text-clip`. Keep `text-balance sm:truncate`. The wrap behavior on mobile comes from removing the bare `truncate`; no additional clip utility needed.

**`src/routes/_authenticated/route.tsx:661`**
- Severity: should-fix
- What: `CreateTaskFabSlot` uses `pathname.startsWith('/settings')` — hardcoded string check bypasses TanStack Router's type-safe matching.
- Why: If settings route path changes, FAB reappears silently with no compile error.
- Fix: Use `useMatch({ from: '/settings', shouldThrow: false })` or the typed route id equivalent.

**`src/features/dashboard/components/AiAssistantCard.tsx:108`**
- Severity: should-fix
- What: `h-full` removed from `<section>`. If the parent grid uses default `align-items: stretch`, removing `h-full` causes the card to shrink to content height on desktop instead of filling the grid cell.
- Why: Potential desktop layout regression — desktop card heights may no longer match siblings.
- Fix: Add `sm:h-full` (restore stretch on non-mobile), keep mobile-only `min-h-[min(320px,55vh)]`.

### NIT

**`src/features/settings/UsersManagementPage.tsx:384-485`**
- Severity: nit
- What: Loading, error, and empty-state text are duplicated between the mobile card block (`md:hidden`) and the desktop table block (`hidden md:block`).
- Fix: Extract state strings as constants or small helper components referenced from both blocks.

**`src/features/task-create/CreateTaskDialogFooter.tsx:593`**
- Severity: nit
- What: `flex-col-reverse` → `flex-col` changes visual button order on mobile stacks. Needs manual phone verification that `FooterStart → Cancel → Next` (DOM order) is intended UX.
- Fix: Verify on actual mobile. If intentional, close the nit.
