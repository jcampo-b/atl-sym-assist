## Findings

### Blockers

**`database/migrations/0001_01_01_000000_create_users_table.php:26-49`**
- **What's wrong:** 5 new columns (`last_login_at`, `linked_owner_id`, `linked_tenant_id`, `linked_vendor_id`, `linked_vendor_emp_id`) added to the base migration.
- **Why:** RULES.md: "Never add new columns to a base migration; always create a new timestamped migration instead." Existing environments will silently miss the columns.
- **Fix:** Move to a new `2026_06_XX_add_linked_ids_and_last_login_to_users_table.php` migration.

**`app/Modules/Users/Services/UserService.php:713`**
- **What's wrong:** `User::where('rm_user_id', $userId)` — `$userId` is the SA `users.id` (from the route), but the query filters by `rm_user_id`. Wrong column.
- **Why:** Logic bug — these two IDs are different. Will silently hit the wrong user or return 404.
- **Fix:** Replace with `User::findOrFail($userId)`.

### Should-fix

**`TenantOnboardingSteps.php:1513` / `VendorOnboardingSteps.php:1588`**
- Both call `RentManagerOwnerMapper::detectMissing()` — a generic utility misplaced on the Owner mapper. Confusing coupling for readers of tenant/vendor code.
- **Fix:** Extract to a shared utility or document the intentional reuse.

**`OnboardingMeController.php:16`**
- `Auth::user()` types as `Authenticatable|null`; `resolveMe(User $user)` expects concrete `User`. PHPStan level 5 will flag this.
- **Fix:** `assert($user instanceof User)` after fetching to narrow the type.

**`UserController.php:1662-1668`**
- Reads `$request->validated()` raw and casts manually. AGENTS.md requires FormRequest helpers (`integer()`, `string()`).
- **Fix:** Use `$request->integer('entity_id')` and `$request->string('entity_type')`.

**`.env.example:27` — `RM_SA_VENDOR_EMP_ROLE_ID=`**
- Intentionally empty with no inline comment. RULES.md: "Add an inline comment for any intentionally empty env var."
- **Fix:** Add `# Leave empty until vendor employee role is configured in RM`.

### Nits

- `UserService::link()` default match arm is unreachable — `entity_type` already validated by `LinkUserRequest`. Remove it.
- Route-file comments in Spanish — translate to English.
- `.env.example` missing trailing newline (`\ No newline at end of file`).
